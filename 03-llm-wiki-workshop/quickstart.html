Skill功能

Step 3：設定環境與啟動

cd my-wiki-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # 填入 GEMINI_API_KEY
uvicorn src.server.main:app --reload --port 8000

瀏覽器開啟 http://localhost:8000 → 看到 💬 Chat + 📚 Wiki 雙分頁。

🧠 Wiki 三層模式

knowledge/ ├── raw/ → 唯讀原始資料（人類丟進來，AI 只讀不改） ├── wiki/ → 結構化知識（AI 維護，人類可審閱） └── schema.md → 規則定義（控制 AI 行為邊界）
原則說明
來源與衍生分離raw/ 保留原始，wiki/ 是 AI 萃取版本
Schema 約束AI 只能用 schema 定義的 type/status
Append-only loglog.md 只追加不刪改（審計軌跡）
雙向連結[[page]] 語法建構知識圖譜

⚠️ 常見問題

錯誤原因解法
RAG 回答沒引用 Wiki沒有 ingest確認 wiki/ 下有頁面
ingest 後 wiki/ 是空的raw/ 沒檔案複製 sample-docs/ 到 raw/
搜不到頁面index.md 沒更新重新觸發 ingest
No module named 'xxx'沒在 venv 中source .venv/bin/activate + pip install
Gemini 沒引用來源API Key 未設定確認 .env 有 GEMINI_API_KEY
