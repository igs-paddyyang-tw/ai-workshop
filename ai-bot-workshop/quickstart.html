4Gemini API 對話（Bot 即時回應）

第二堂開場：讓 Bot 會思考

接入 Gemini API

📝 加入 Gemini API 對話能力，Bot /chat 用 API 即時回話，
一般文字訊息也走 AI 對話

→ 產出 src/llm/gemini_chat.py（Gemini API SDK 封裝）

取得 Gemini API Key（免費）

  • 前往 aistudio.google.com/apikeys
  • 點擊「Create API Key」→ 複製
  • 填入 .env：GEMINI_API_KEY=your_key
免費額度：60 req/min、1,000 req/day。Step 6 的 Gemini CLI 也共用此 Key。

驗證（📱 Telegram）

📱 /chat 你是誰 → 1-3 秒收到 AI 回應 ✅
📱 什麼是 Python → 收到 AI 回應 ✅
