🧠 知識庫核心規則

所有知識先進 raw/ → 排程 LLM ingest → wiki/（唯一產出方式） 讀取優先： 1️⃣ 自己的 knowledge/wiki/（私有） 2️⃣ 根目錄 knowledge/wiki/（共用） 寫入規則： Agent → 自己的 knowledge/raw/ 人類 → 根目錄 knowledge/raw/ wiki/ → 只能由 LLM ingest 產出 ❌ 不可手動寫

python3 .kiro/skills/ark-kiro-init/scripts/build_kiro.py --clone-skills my-team
