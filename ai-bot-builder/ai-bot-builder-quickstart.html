❓ FAQ

Q：一句話就能建好？
是的。ark-ai-bot-builder 內含完整模板，一次產出所有檔案。後續可逐步擴充。

Q：Bot 沒回應？
確認 .env Token 正確 + 沒有其他程式在 polling 同一 Token + 先按 /start。

Q：/daily 抓不到新聞？
優先用 Hacker News（純 HTML 最穩定）。確認 pip install httpx beautifulsoup4。
