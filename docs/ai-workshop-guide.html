📗 課程 A：AI Agent 開發入門

🏗️ 駕馭工程（Steering Engineering）

傳統開發：你寫每一行程式碼。
駕馭工程：你設計方向，AI 執行細節。

你做的事AI 做的事
設計 SOUL（人格方向）產出符合人格的回應
拷問需求、確認 Spec依 Spec 產出程式碼
丟入知識素材建立 RAG 索引、有依據的回答

你是方向盤，AI 是引擎。駕馭 ≠ 放手，駕馭 = 你決定去哪。

📘 課程 B：AI Agent Team 實戰

🔄 迴圈工程（Loop Engineering）

課程 A 教「線性流程」：輸入 → 處理 → 輸出。
課程 B 教「迴圈系統」：輸出回饋成下次的輸入，系統自動進化。

  派工 → 執行 → 產出 → 記憶 → 知識成長 → 下次更準
   ▲                                              │
   └──────────── 排程自動觸發 ◀────────────────────┘
線性（課程 A）迴圈（課程 B）
你 /assign → 做一次排程自動觸發 → 每天做
你加知識 → 能回答Agent 自己累積 → 越來越準
一個 Agent 做一件事一群 Agent 分工

設計迴圈，不是設計步驟。讓系統自己跑、自己學、自己成長。

自演化機制（Self-Evolution）

知識層自演化

對話 → memory.py 自動寫入 knowledge/raw/
    → 定期 ingest → knowledge/wiki/ 成長
    → RAG 查詢更精準
    → Agent 回答越來越好

Skill 層自演化

使用 Skill → 觀察效果
    → ark-grill-me 拷問改進點
    → ark-superpowers 重寫 Spec
    → ark-code-spec-validator 驗證
    → Skill 品質持續提升
