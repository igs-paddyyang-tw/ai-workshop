## 跳堂指引

每堂課設計為可獨立運行，但連續上效果最佳。

| 你的狀況 | 建議路徑 |
|---------|---------|
| 完全新手 | 01 → 02 → 03 → 04 → 05（完整路徑） |
| 有 Bot 經驗 | 02 → 03 → 04 → 05（跳過 01） |
| 想學平台架構 | 02 → 03（只做兩堂） |
| 想學 Skill 開發 | 04 單堂即可（獨立） |
| 想學 RAG/知識庫 | 05 單堂即可（獨立） |
| 急用，5 分鐘出成品 | 直接 `build_team.py`（快速路徑） |
