## 三層分工對應

> 舊版這裡畫的是「五層架構」（Gateway / Coordinator / Services / Runtime / Knowledge）。
> 那是**手搭時代**的圖 —— 那五層現在全在套件裡，學員碰不到也不需要碰。
> 現在的軸線是**三層分工**：架構 → 人格 → 技能。

```
                        01        02        03        04        05
                     ┌──────────┬──────────┬──────────┬──────────┬──────────┐

  builder / yaml     │agents.yaml          │          │team.yaml │scheduler │
                     ├──────────┼──────────┼──────────┼──────────┼──────────┤
② 人格（SOUL）        │ ████████ │          │          │ ████████ │          │
  ark-agent-init     │ 八段式   │          │          │ 新角色   │          │
                     ├──────────┼──────────┼──────────┼──────────┼──────────┤
③ 技能（Skills）      │          │ ████████ │          │ ████████ │          │
```

## 跳堂指引

每堂課設計為可獨立運行，但連續上效果最佳。

| 你的狀況 | 建議路徑 |
|---------|---------|
| 完全新手 | 01 → 02 → 03 → 04 → 05（完整路徑） |
| 有 Bot 經驗 | 02 → 03 → 04 → 05（跳過 01） |
| 想學 Skill 開發 | 01 → 02（兩堂即可） |
| 想學 RAG/知識庫 | 03 單堂即可（獨立） |
| 想學團隊協作 | 04 → 05（兩堂） |
| 急用，5 分鐘出成品 | 直接跑 `samples/ai-team-agent`（裝 wheel → sync_skills → start） |
