# 捕魚機 vs 老虎機 — 產品定位比較

## 產品類型比較

| 維度 | 捕魚機（Ocean King 系列） | 老虎機（Super Ace 系列） |
|------|--------------------------|------------------------|
| 操作方式 | 主動射擊（技巧型） | 被動轉盤（運氣型） |
| 玩家參與度 | 高（即時操作） | 低（按鈕等結果） |
| 單局時間 | 持續（無明確結束） | 極短（3-5 秒/轉） |
| 社交性 | 強（多人同場競爭） | 弱（獨立遊玩） |
| 技巧占比 | 30%（瞄準+時機） | 5%（下注策略） |
| 畫面需求 | 高（3D 即時渲染） | 中（2D 動畫為主） |
| 機台成本 | 高（大螢幕+多人座位） | 低（單人機台） |

## 目標玩家差異

### 捕魚機玩家
- 偏好「操作感」和「成就感」
- 喜歡多人互動和競爭
- 願意花時間在單一場次
- 年齡層偏年輕（20-35）

### 老虎機玩家
- 偏好「期待感」和「驚喜感」
- 接受獨立遊玩
- 喜歡快節奏高頻率
- 年齡層較廣（25-50）

## 營收模式比較

### 捕魚機
- 投幣/子彈計費（射擊消耗）
- 玩家技巧影響消耗速度
- ARPU 較高但玩家數較少
- 機台回收期較長（成本高）

### 老虎機
- 押注/轉盤計費
- RTP 決定長期回收率
- ARPU 分散但玩家基數大
- 機台回收期短（成本低）

## 市場趨勢（2024-2025）

### 捕魚機趨勢
1. **從街機到手遊**：移動端成長 40%+
2. **Boss 機制升級**：更戲劇化的 Boss 戰
3. **社交功能強化**：組隊、公會、排行榜
4. **畫面持續升級**：次世代 3D、粒子特效

### 老虎機趨勢
1. **Megaways 普及**：從 243 Ways → 117,649 Ways
2. **Cascading 成主流**：消除+連鎖取代傳統轉盤
3. **Buy Feature**：直接購買 Bonus Round
4. **品牌 IP 合作**：影視、動漫授權主題

## 結論：互補而非競爭

捕魚機和老虎機不是直接競爭關係，而是互補：
- 同一個玩家可能兩種都玩（心情不同選擇不同）
- 遊藝場同時擺設兩種 = 覆蓋更多玩家類型
- 手遊平台同時上架 = 提高整體留存率

**產品策略建議**：同時開發兩線產品，共用後台和玩家系統，前端差異化。
