# Super Ace 超級王牌老虎機競品分析

## 遊戲概覽

Super Ace 是 JILI Games 開發的撲克牌主題老虎機，以高 RTP（97%）和創新的 Golden Card 機制聞名，在菲律賓和東南亞市場極受歡迎。

## 基本規格

| 項目 | 數值 |
|------|------|
| 開發商 | JILI Games |
| 機台結構 | 5 軸 × 4 列 |
| 賠付方式 | 1,024 Ways to Win |
| RTP | 97%（業界頂級） |
| 波動度 | 低中（Low-Medium） |
| 主題 | 撲克牌（A/K/Q/J/10/9/8/7） |

## 核心機制

### 1. Cascading Reels（消除滾輪）
- 中獎符號消除後，上方符號下落填補
- 連續消除 = 連續中獎（Combo）
- 每次 Combo 倍率遞增

### 2. Golden Card（黃金卡牌）⭐ 核心特色
- 特定條件下普通符號變成金色
- 金色符號被消除時 → 轉變為 Wild（百搭）
- Wild 留在原位，增加後續中獎機率
- **策略要素**：觀察波動模式，調整下注時機

### 3. Free Game Bonus（免費遊戲）
- **觸發**：3 個以上 Scatter 符號出現
- **獎勵**：10-20 次免費轉動
- **Sticky Wild**：免費遊戲期間 Wild 會黏在位置上
- **累積效果**：越多 Wild 黏住，後面越容易中大獎

### 4. Progressive Multiplier（累進倍率）
- 連續消除時倍率自動提升
- 延長遊戲回合 = 更高倍率
- 獎勵持續遊玩的玩家

## 設計亮點

1. **撲克牌文化共鳴**：東南亞玩家熟悉的卡牌符號
2. **低門檻高天花板**：低波動保底，Golden Card 創造大獎機會
3. **視覺回饋強烈**：金色變色 + 消除動畫 + 倍率飛升
4. **策略深度**：不只是按按鈕，可觀察模式調整下注

## 市場表現

- **主力市場**：菲律賓（#1 JILI 遊戲）
- **玩家定位**：休閒玩家 + 中度博弈玩家
- **競爭優勢**：97% RTP 遠高於業界平均（94-96%）
- **延伸版本**：Super Ace Deluxe、Super Ace Ultimate
