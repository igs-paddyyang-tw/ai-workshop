# 遊戲 KPI 核心指標

## 用戶規模

| 指標 | 定義 | 計算 |
|------|------|------|
| DAU | 日活躍用戶 | 當天登入的唯一用戶數 |
| MAU | 月活躍用戶 | 當月登入的唯一用戶數 |
| DAU/MAU | 黏性比 | DAU ÷ MAU，健康值 > 20% |
| 新增用戶 | 當日首次登入 | 新裝置 / 新帳號首次開啟 |

## 留存率

| 指標 | 定義 | 健康基準（手遊） |
|------|------|---------------|
| D1 留存 | 次日留存率 | > 40% |
| D7 留存 | 第 7 天留存率 | > 20% |
| D30 留存 | 第 30 天留存率 | > 10% |
| Cohort 分析 | 同批用戶留存曲線 | 用於趨勢比較 |

## 營收指標

| 指標 | 定義 | 計算 |
|------|------|------|
| ARPU | 每用戶平均收益 | 總收益 ÷ DAU |
| ARPPU | 每付費用戶平均收益 | 總收益 ÷ 付費用戶數 |
| 付費率 | 付費滲透率 | 付費用戶 ÷ DAU |
| LTV | 用戶生命週期價值 | ARPU × 平均留存天數 |

## 遊戲行為

| 指標 | 定義 |
|------|------|
| 場次數 | 每日平均對局 / 關卡次數 |
| 時長 | 每次 session 時間長度 |
| 關卡通過率 | 某關卡通過 ÷ 嘗試次數 |
| 虛擬貨幣消耗 | 金幣 / 鑽石等消費趨勢 |

## 捕魚機 / Slot 特有指標

| 指標 | 定義 |
|------|------|
| RTP | Return to Player，實際返還率 |
| 下注量 | 每日總下注金額 |
| 爆分頻率 | 大獎觸發次數 / 場次 |
| 平均押注 | 平均每局押注額 |

## 分析常見問題

- **DAU 突降** → 先查是否有版本更新、活動結束、渠道問題
- **D7 留存低** → 通常是早期遊戲體驗問題（新手引導）
- **ARPU 下滑** → 檢查付費點位、活動強度、競品促銷

## 資料來源

- 埋點系統（GA / Firebase / 自建）
- 後台 BI Dashboard
- 渠道報告（App Store Connect / Google Play Console）
