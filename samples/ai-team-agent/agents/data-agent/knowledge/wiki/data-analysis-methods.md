# 數據分析方法論

## 分析流程

1. **定義問題** — 明確要回答什麼業務問題
2. **資料收集** — 確認資料來源和品質
3. **資料清洗** — 處理缺失值、異常值
4. **分析建模** — 選擇適合的分析方法
5. **產出洞察** — 將結果轉化為可行動建議

## 常用分析方法

| 方法 | 適用場景 | 產出 |
|------|---------|------|
| 趨勢分析 | KPI 追蹤 | 時間序列圖 + 趨勢解讀 |
| 比較分析 | A/B 測試、競品對比 | 差異量化 + 統計顯著性 |
| 漏斗分析 | 轉換率優化 | 各階段流失率 + 瓶頸定位 |
| 群組分析 | 用戶分群 | 群組行為差異 + 策略建議 |
| 歸因分析 | 行銷效果 | 各渠道貢獻度 |

## 報告格式

```
## 摘要（一段話結論）
## 關鍵發現（3-5 個 bullet）
## 數據佐證（圖表 + 數字）
## 建議行動（具體可執行）
```
