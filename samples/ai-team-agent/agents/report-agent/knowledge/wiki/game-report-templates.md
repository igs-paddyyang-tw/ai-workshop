# 遊戲報告模板規範

## 報告類型

| 類型 | 頻率 | 受眾 | 格式 |
|------|------|------|------|
| 每日日報 | 每日 08:30 | 管理層 | HTML / Markdown |
| 每週週報 | 每週一 09:00 | 全團隊 | HTML |
| 競品分析報告 | 按需 | PM / 策劃 | Markdown |
| 專項數據報告 | 按需 | 數據分析 | Markdown + 圖表 |

## 每日日報模板

```markdown
# 🎮 遊戲日報 {YYYY-MM-DD}

## 📊 今日關鍵指標

| 指標 | 今日 | 昨日 | 變化 |
|------|------|------|------|
| DAU | {N} | {N} | {+N%} |
| 新增用戶 | {N} | {N} | {+N%} |
| 收益 | ${N} | ${N} | {+N%} |
| D1 留存 | {N}% | {N}% | {+N%} |

## 📰 市場動態

{market-agent 產出的新聞摘要}

## 🔍 競品動態

{market-agent 產出的競品更新}

## 💡 今日洞察

{data-agent 分析結論，2-3 條重點}

## ⚠️ 待關注

{需要跟進的問題或異常}
```

## 競品分析報告模板

```markdown
# 競品分析報告：{主題}

**分析日期**: {日期}
**分析人**: report-agent
**資料來源**: market-agent

## 摘要（Executive Summary）

{3 句話：做了什麼、發現什麼、建議什麼}

## 競品概覽

{競品卡片表格}

## 深度分析

### 玩法機制比較
### 付費設計比較
### 美術風格比較
### 用戶評價比較

## 市場機會

## 行動建議
```

## 報告品質標準

| 標準 | 要求 |
|------|------|
| 結構 | 必須有摘要、正文、結論三段 |
| 數據 | 所有數字必須標明來源 |
| 圖表 | 每個圖表必須有標題和說明 |
| 字數 | 日報 ≤ 500 字，週報 ≤ 2000 字 |
| 格式 | 一致的 Markdown 格式，標題階層正確 |

## 與其他 Agent 協作

- **data-agent** → 提供 KPI 數據與分析
- **market-agent** → 提供競品資訊與新聞
- **pm-agent** → 確認報告需求與驗收
