# 遊戲競品分析方法

## 分析框架（SWOT + 4P）

### SWOT 快速評估

| 面向 | 問題 |
|------|------|
| Strength | 這款遊戲的核心賣點是什麼？ |
| Weakness | 玩家最常抱怨什麼？ |
| Opportunity | 市場缺口在哪裡？ |
| Threat | 哪些競品最像？ |

### 4P 分析

| P | 分析維度 |
|---|---------|
| Product | 玩法機制、美術風格、功能特色 |
| Price | 付費設計、首儲、月卡、抽卡機率 |
| Place | 上架平台、渠道、地區 |
| Promotion | 廣告素材、活動類型、KOL 合作 |

## 捕魚機 / Slot 競品關鍵指標

| 指標 | 資料來源 |
|------|---------|
| 版本更新頻率 | App Store / Google Play 版本記錄 |
| 評分 / 評論數 | Store 頁面 |
| 下載量排名 | App Annie / Sensor Tower |
| 廣告投放量 | Meta Ads Library / AdSpy |
| 玩法特色 | 實機體驗 + 截圖分析 |

## 主要競品清單（手遊捕魚 / Slot）

| 遊戲 | 類型 | 特色 |
|------|------|------|
| Ocean King | 捕魚 | 老牌、街機移植、高知名度 |
| Super Ace | Slot | 3x3 Classic Slot，Philippine 市場 |
| Fishing War | 捕魚 | PvP 實時對戰 |
| Cash Frenzy | Slot | 高頻率活動 + 每日登入 |

## 資料蒐集 SOP

```
1. App Store / Google Play 搜尋關鍵字（捕魚、fishing、slot）
2. 下載前 20 名截圖記錄
3. 安裝並體驗核心玩法（首日流程）
4. 記錄付費設計（何時 popup、價格帶）
5. 查評論關鍵詞（喜歡什麼 / 討厭什麼）
6. 整理為競品卡片（標準格式）
```

## 競品卡片標準格式

```markdown
## {遊戲名稱}

- **類型**: 捕魚 / Slot / 混合
- **評分**: X.X / 5（N 則評論）
- **更新頻率**: 每 X 天一版
- **付費設計**: 首儲禮包 / 月卡 / 課金抽卡
- **核心玩法**: ...
- **特色功能**: ...
- **評論關鍵詞（正面）**: ...
- **評論關鍵詞（負面）**: ...
- **市場機會**: ...
```

## 與其他 Agent 協作

- 產出的競品資料 → **data-agent** 做量化分析
- 產出的洞察 → **report-agent** 彙整成報告
