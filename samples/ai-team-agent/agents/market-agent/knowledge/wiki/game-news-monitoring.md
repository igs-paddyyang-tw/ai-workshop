# 遊戲新聞監控與輿情分析

## 監控目標

| 類型 | 內容 | 頻率 |
|------|------|------|
| 產業新聞 | 融資、合併、新遊上市 | 每日 |
| 競品動態 | 版本更新、活動上線、下架 | 每日 |
| 玩家輿情 | 評論、論壇討論、社群反應 | 每日 |
| 政策法規 | 版號、上架限制、未成年保護 | 每週 |

## 資訊來源

### 新聞媒體
- 遊戲葡萄（gameores.com）
- DataEye 研究院
- 伽馬數據
- App Annie Blog
- Sensor Tower Blog

### 社群平台
- 巴哈姆特（台灣玩家）
- PTT / Dcard（台灣）
- 微博 / 抖音（中國市場）
- Facebook Gaming 粉絲頁
- Discord 官方伺服器

### 應用商店
- App Store 評論（前 5 頁）
- Google Play 評論（最新 + 最差）

## 新聞爬取 SOP

```python
# 1. 設定關鍵字
keywords = ["捕魚遊戲", "老虎機", "fishing game", "slot game", "Ocean King"]

# 2. 爬取目標網站
sources = ["gameores.com", "app store rss", "google play rss"]

# 3. 篩選相關性（關鍵字命中）
# 4. 去重（URL 或 title hash）
# 5. 輸出標準格式
```

## 輸出格式（每日新聞摘要）

```markdown
## {日期} 遊戲產業動態

### 🔥 重要新聞
- [{標題}]({URL}) — {一句話摘要}

### 🎮 競品動態
- {遊戲名}: {更新/活動/事件}

### 💬 玩家聲音
- 正面：{關鍵詞}
- 負面：{關鍵詞}

### 📊 今日觀察
{一段簡短洞察}
```

## 輿情評分規則

| 分數 | 定義 |
|------|------|
| +2 | 強烈正面（讚美、推薦、五星） |
| +1 | 輕微正面（普通好評） |
| 0 | 中性（說明、問題） |
| -1 | 輕微負面（小問題、建議） |
| -2 | 強烈負面（差評、投訴、退款） |

## 與其他 Agent 協作

- 爬取的新聞資料 → **data-agent** 量化分析趨勢
- 整合後的市場報告 → **report-agent** 產出 HTML 日報
