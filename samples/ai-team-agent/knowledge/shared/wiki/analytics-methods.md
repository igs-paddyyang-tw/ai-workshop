# 數據分析方法

## 數據源

- SQLite（`data/*.db`）
- 外部 API
- CSV 匯入

## 核心 KPI

| 指標 | 說明 |
|------|------|
| 日活（DAU） | 每日活躍使用者 |
| 留存率 | 次日/7日/30日 |
| 轉換率 | 目標行為完成比例 |
| 成本效率 | 投入/產出比 |

## 趨勢分析

- 同比（YoY）：年對年比較
- 環比（MoM）：月對月比較
- 移動平均：平滑短期波動

## 輸出規範

每份分析必須包含：表格 + 圖表 + 一句話洞察。
