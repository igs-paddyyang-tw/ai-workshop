# 專案管理方法論

## 核心流程

```
需求 → 拆解 → 派工 → 追蹤 → 驗收
```

## 任務格式規範

每個任務必須包含：

| 欄位 | 說明 |
|------|------|
| 標題 | 明確動詞開頭 |
| 描述 | 背景與目的 |
| 驗收條件 | 可衡量的完成標準 |
| 大小 | S（<2h）/ M（2-8h）/ L（>8h） |

## 每日 Standup

三段式回報：
1. 昨日進度
2. 今日阻礙
3. 今日計劃
